# コイル・バクテリア（試作）

らせんで囲って、ダッシュで締める — Vampire Survivors 風 × slither.io のオフライン単機プロトタイプ。

**遊ぶ:** https://ryuto794.github.io/coil-bacteria/

**言語 / Language:** タイトル画面の右上で 日本語 / English を切り替え。Switch between 日本語 and English at the top right of the title screen.

## 操作

| | PC | スマホ |
|---|----|--------|
| 移動 | マウス方向 / WASD / 矢印 | 指でドラッグ |
| ダッシュ | クリック / スペース（長押しで延長） | 短タップ / 右下 DASH / 2本指（長押しで延長） |
| レベルアップ | クリック or `1` `2` `3` | カードをタップ |
| 引き直し / スキップ | `R` / `X`、またはボタン | ボタン |
| ポーズ | `Esc` / `P`、または左上のボタン | 上のボタン |
| リトライ | `R` / ボタン | ボタン |

頭だけが弱点。尾で敵の群れを囲み（何周も巻くとチャージUP）、ダッシュで締めて一掃する。

敵がときどき落とすアイテムは、回復・XP の吸い寄せ・敵を止める、の 3 種。爆発菌は倒すと周りを巻き込み、連鎖する。大きい敵は殻を持ち、殻の数だけ巻かないと倒せない。毒素菌が残す霧には頭で入らないこと。尾が伸びるとボスが出て、倒すと次の大きさ（細菌 → 細胞 → 細胞核）へ。細胞核のボスを倒すとクリア。クリアしたあとはエンドレスで続けられる。集めた DNA はタイトルでスキンの解放に使える。ミッションを達成すると DNA やレアカードがもらえる。
