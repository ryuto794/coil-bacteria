# コイリオ / Coilio（試作）

らせんで囲って、ダッシュで締める — Vampire Survivors 風 × slither.io のオフライン単機プロトタイプ。

**遊ぶ:** https://ryuto794.github.io/coil-bacteria/

**言語 / Language:** タイトル画面の右上で 日本語 / English を切り替え。Switch between 日本語 and English at the top right of the title screen.

## 操作

| | PC | スマホ |
|---|----|--------|
| 移動 | マウス方向 / WASD / 矢印 | 画面のどこでも、触れた場所から指を動かした向きへ進む（設定で「触れた方向へ進む」にも変えられる） |
| ダッシュ | クリック / スペース（長押しで延長） | 短タップ / 右下 DASH / 2本指（長押しで延長） |
| レベルアップ | クリック or `1` `2` `3` | カードをタップ |
| 引き直し / スキップ | `R` / `X`、またはボタン | ボタン |
| ポーズ | `Esc` / `P`、または左上のボタン | 上のボタン |
| リトライ | `R` / ボタン | ボタン |

頭だけが弱点。尾で敵の群れを囲み（何周も巻くとチャージUP、最大10重）、ダッシュで締めて一掃する。

尾の通り道でできた輪は、ぜんぶ別々に数える。途中に 1 度だけ、群れが 20 秒追ってくる「ラッシュ」がある（ダッシュで突き放す）。輪が続けて締まると連鎖になり、あとの輪ほど強い。向きを変えて 8 の字に巻くと「∞ 締め」。ダッシュ中とその直後は体が伸び、伸びている間に閉じた輪はその場でダッシュ締めになる。

敵がときどき落とすアイテムは、回復・バリア・XP の吸い寄せ・敵を止める、の 4 種。レベルアップの途中で、トゲ・電流・炎・氷の系統から 1 つを選ぶ。ボスを倒すと自分が大きくなり、それまでの敵は小さくなって頭で触れるだけで潰せる。細胞の世界からは、ときどき白血球が追ってくる（逃げるか、7回巻いて倒す）。ほかに、突進してくる敵、撃ってくる敵（弾は尾で防げる）、倒すと分裂する敵が出る。爆発菌は倒すと周りを巻き込み、連鎖する。大きい敵は殻を持ち、殻の数だけ巻かないと倒せない。毒素菌が残す霧には頭で入らないこと。尾が伸びるとボスが出て、倒すと次の大きさ（細菌 → 細胞 → 細胞核）へ。細胞核のボスを倒すとクリア。カードにはトゲ系と電流系の系統があり、ボスのカプセルで 2 段階まで進化して姿が変わる。クリアしたあとはエンドレスで続けられる。集めた DNA はタイトルでスキンの解放に使える。ミッションを達成すると DNA やレアカードがもらえる。

大きくなったあとは、形も動きも違う敵が来る：直進して通り過ぎる桿菌、回りながら寄るらせん菌、鎖でうねる連鎖球菌、尾に取りつくファージ（ダッシュで振り落とす）、小さい粒子を放つ巨大ウイルス、ブーメランのように行って戻るミカヅキモ、X 字の染色体（倒すと 2 本に分かれて走る）、Y 字の抗体、回りながら来る DNA 鎖。ときどき、画面に収まらないほど大きい単細胞生物（ゾウリムシ・ミドリムシ・タイヨウチュウ）が横切る。

タイトル画面でステージを選ぶ。1 つのステージはさっと遊べる長さにしてあり（クリアまでのボスは軽め）、クリアしたあとはエンドレスで遊び続けられる（戻ってくるボスはだんだん重くなる）。ステージ 1「体の中」をクリアすると、ステージ 2「池の水」（原生生物 → ミジンコ → クマムシ）が開く。クマムシの世界では、クマムシには締め以外の何も効かず、締めても死なずに乾眠して、12 秒で生き返る。乾眠している間に頭で潰すと倒せる。モノアラガイのねばねばの跡では遅くなる。ボスのオニクマムシは丸まって転がってくる（尾に当たると跳ね返る）。締めて乾眠させ、頭で 2 回潰すと倒れる。ミジンコの世界のボスのヒドラは、子ヒドラの群れを連れてくる：子がついている間は本体の殻が割れないので、子を 1 匹ずつ巻いて剥がしてから倒す。池の水の巨大なミジンコは、殻を割ると赤くなって暴れだす（赤い帯が突進の合図）。ステージ 2 をクリアすると、ステージ 3「蠱毒」（試作）が開く：自分と同じ姿の敵がたくさんいて、ぐるぐる回っていたり、突っ込んできたり、こちらを囲んできたりする。ボスは巨大な同族。蠱毒をクリアすると、ステージ 4「蟻地獄」（試作）が開く：画面いっぱいの巨大なアリジゴクのあごが下から迫ってくるので、上へ逃げながら、転がり落ちてくる虫を巻いて吸収し、尾を伸ばす。あごに追いつかれると噛まれる。尾が伸びきるたびに自分が大きくなり、アリジゴクはだんだん小さく見えてくる。すり鉢のふちまで大きくなると、アリジゴクが巣から出てくる。殻はないが、体ごと巻けるほど大きくならないと倒せない。その先のステージ 5「巨人の国」（試作）は、今までの巨大生物だけが出てくる世界：最初から大きくて強い自分（長い尾、HP 200）で、大きく回って巨大生物をまとめて巻く。ボスはヤゴ（下あごを一瞬で伸ばして捕まえる）。締めるたびに脱皮して大きくなり、最後は羽化してトンボになって飛び回る。その先のステージ 6「蜘蛛の巣」（試作）は、地面に網が張ってあって網の中は遅い。巻いて締めると網が切れる。クモがたくさん出てきて、糸に当たると絡まる（ダッシュでほどける）。ボスはジョロウグモ。

タイトル画面の「図鑑」で、たどり着いたスケールまでの敵を見られる。

ボスはそれぞれ技を持つ：巨大菌は構えてから突進し、巨大細胞は弾を輪にばらまき、マクロファージは赤い円の場所へ飛びついて閉じ、ヒドラはでんぐり返しで寄ってくる。どれも出る前に予告があり、終わったあとに隙がある。

スキンは 19 種類（縞、グラデーション、走る光、目の違い）。プレイでたまる DNA で解放する。見た目だけで、強さは変わらない。

## 開発メモ

- 本体は `index.html` のみ（バニラ JS + Canvas）。ビルドなしで動く。
- 配布用のビルド（体験版 / 製品版）: `cd tools && npm install && node build.mjs demo`（または `full`）。出力は `dist/`。
- Claude Code 向け: `CLAUDE.md` / 詳細引き継ぎ: `HANDOFF.md`
- テスト: `?demo` / `?demo&swarm` / `?tail=1900` / `?boss` / `?shell` / `?toxin` / `?titan` / `?nosave` / `?skin=neon` / `?lang=en` / `?splash` / `?t=600` / `?give=…`
